# Image guide

New Pexels images are sorted by subject. Original Pexels filenames retain the photographer name and image ID.

| Folder | Use |
| --- | --- |
| `funds/community/` | Group collaboration, community projects, and shared goals |
| `funds/community/rural/` | Rural community and food-support imagery |
| `funds/community/water/` | Water access and community-support imagery |
| `funds/education/` | School and classroom imagery |
| `funds/savings/` | Savings imagery and illustrations |
| `funds/business/` | Business and finance imagery |
| `events/` | Team-building and group-event imagery |
| `africa/landscapes/`, `africa/nature/`, `africa/places/` | Regional scenery and place imagery |

The Pexels images were provided with the project. Their filenames preserve source identification. Keep these filenames and their folders together when deploying assets.
